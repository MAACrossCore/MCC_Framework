# 活动任务识别区域可视化

坐标使用 MaaFW Pipeline 的 `1280×720` 基准坐标，运行时由控制器按实际
画面分辨率适配。

- `first_stage_research_institute.svg`：困难第一关 OCR 区域、OCR 跟随点击方式，
  以及每轮两次向右拖拽的起止点。

## 后续活动替换

当前活动第一关特征集中在 `assets/resource/pipeline/base/活动.json` 的
`活动_困难第一关_研究所` 节点。更换活动时，通常只需要调整该节点的
`expected` 和 `roi`；因为动作没有固定 `target`，点击位置会自动跟随 OCR
识别到的文字框。

拖拽与重试由三个通用定位节点负责：

1. `活动_困难第一关定位_右拖第一次`
2. `活动_困难第一关定位_右拖第二次`
3. `活动_困难第一关定位_识别分派`

识别分派未找到当前第一关特征时，会重新执行完整的两次拖拽。
两次拖拽后分别等待 `1400ms` 和 `1800ms`；OCR 命中并点击文字后再等待
`1800ms`，用于兼容低帧率或页面惯性尚未停止的情况。
