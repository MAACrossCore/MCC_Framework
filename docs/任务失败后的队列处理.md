# 任务失败后的队列处理

自2026-10-07起，普通游戏任务失败时结束当前任务，保留失败状态，并继续后续任务。
失败任务剩余的重复次数不再执行。

MCC调用约定的可选Pipeline入口，不在interface.json中添加非标准字段。
本项目入口为任务失败_返回主页，位于resource/pipeline/base/任务失败恢复.json，包含MPE位置。
恢复优先确认主页，其次识别主页键、返回键、奖励弹窗。点击次数有限；恢复未成功也继续后续任务。
恢复不交付订单、不购买物品、不开始战斗。

用户点击停止后，包括主页恢复在内的操作及后续任务全部停止。
连接或Agent初始化失败仍结束整个队列，因为后续任务无法执行。
队列内单项失败不影响其它任务的独立结果；队列结束时仍保留存在失败的总体状态。

此行为需要配套的MCC UI修复；仅更新资源不能改变旧版UI停止任务队列的行为。
