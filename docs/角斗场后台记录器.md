# 角斗场后台记录器

启动：在 PowerShell 运行 E:\MAA_crosscore\tools\Start-JdcMonitor.ps1。
停止：运行 E:\MAA_crosscore\tools\Stop-JdcMonitor.ps1。只停止记录，不停止 MCC。

记录器读取 MCC 的 logs 和 debug/maafw.log。检测角斗场任务开始后，约每秒通过 ADB 截取模拟器原始 PNG；拖拽、点击、按下和抬起事件优先补拍。
默认只记录一次：任务成功、失败或用户停止后补拍结束画面，约两秒后自动退出，不继续监听下一次任务。
最多运行两小时、最多保存约 500 MB，达到限制自动结束。只有显式使用 --keep-listening 才持续监听多次任务。
截图本身有耗时，不能保证捕获每一帧或手指移动中的瞬间；时间线同时保存动作参数和截图开始时间，方便区分观察时间与原日志时间。
相同画面只保留一个图片文件，但每次观察都有时间线记录。

全部输出位于 E:\MAA_crosscore\debug\jdc-monitor\时间目录：

- session.json：进程、设备、开始结束时间、数量。
- timeline.jsonl：任务状态、动作坐标及结果、节点日志、截图文件关联。
- screens：完整模拟器截图，不采集桌面或其它窗口。
- 角斗场代码快照.py、角斗场流程快照.json：本次诊断的源码参考。

记录器不修改任务方案，不启动 MCC，不点击或拖拽游戏，也不读取其它应用。
截图和日志可能含游戏 UID、角色和配置路径，不应直接公开上传。
默认优先自动查找 MuMu 和已连接设备；存在多个设备时应使用 monitor_jdc.py 的 --adb 和 --serial 显式指定。
若启动时任务已运行且最近日志无法推断起点，可以使用 --capture-now 手动开始采集。
无需改游戏功能或重启 MCC。源码改动维护仍应保留在 Pipeline/Agent 的既有职责范围内。
