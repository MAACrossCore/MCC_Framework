# v0.8.2

基于 v0.8.1 的维护更新，资源发布包配套 MCCAvalonia v0.1.4。

## 修复

- 角斗场：拖拽结束后统一复核右侧角色名字，只补拖仍在列表的目标角色，不再失败后反复清空整个队伍；最多三轮。用户已实测正常。
- 竞技场：修复带 BOM 的实例配置读取，避免读取失败时静默只执行一次挑战。
- 每日探索：消耗完体力支持超过十次的多批扫荡，批次之间重新进入扫荡页面。
- 主线刷取：从出击、主线剧情进入，识别 07 虚拟场域后接续原关卡流程。
- 基建：调整订单交付与切页时序，减少切页后误交付。
- 任务队列：普通任务失败后结束本项，尝试返回主页并继续下一项；用户主动停止及初始化失败仍停止队列。该功能依赖本次配套 UI。

## 开发辅助

- 新增一次性角斗场后台日志及截图记录脚本，默认不启动，不干预游戏，任务结束后退出。
- 补充 Pipeline/MPE 节点、测试和维护说明。
