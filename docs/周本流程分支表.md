## 〇、总览示意

```
周本(任务入口)
 └─ 周本_次数初始化[C]        agent init：目标先兜底（依然挑战=自选次数；领完即结束=1）
     └─ 首页_出击 →（任务覆盖）活动探索
         └─ 活动探索 ★点击活动探索入口★  post_delay 2000
             ├─ S1 碎星虚影在「应有位置」(=未满)  → 读进度_未满[C] → 点卡片领奖 ★
             └─ S2 不在应有位置 (=满 600/600)      → 周本_碎星虚影_分派 → 左滑找回

★ 点卡片后的三条收场（周本_领奖后_判定）
   C1 进了 BOSS 选择页          → 直接开始挑战
   C2 卡片仍在应有位置          → 再点一次卡片 → BOSS 选择页 → 挑战
   C3 卡片挪走了（已领奖）      → 分派 → 左滑找回 → 读取报酬 → 读进度 → 按进度分派

★ 左滑找回后的两条收场（周本_按进度分派，OCR 满进度）
   D1 满 600/600：case A → 领完即结束 → 通用-返回主页（收工）
                  case B → 继续挑战（默认 next）
   D2 未满      →（on_error）进度未满_继续刷 → 继续挑战
   D3 左滑滑不动了（max_hit 用尽）→ 找不到碎星虚影_收尾 → 领完即结束 → 返回主页（干净收尾，不报错）

挑战循环
   活动探索_碎星虚影 → 周本_BOSS选择页_已进入 → 活动探索_戈里刻虚影 →（关卡）
   → 虚影阿瑞斯/第五关 → 开始战斗 → 步骤1..5 → 战斗中1/2/3 → 战斗结束1/2/3
   → 周本_挑战完成_阿瑞斯/宙斯（次数 +1）→ 周本_次数分派
        ├─ 周本_次数已达[C]（到目标）→ 通用-返回主页（结束）
        └─ 所选关卡 → 再打一场
```

`[C]` = 由 agent（`weekly_run_count`）执行的 Custom 动作/识别；其余全部在管道里。

## 一、主分支：进页面之后（`活动探索.next`）

| # | 情形 | 判据（OCR 文本 @ ROI） | 动作 | 下一跳 |
|---|---|---|---|---|
| S1 | 碎星虚影在「应有位置」= **未满**（顶部数字 <600） | `碎星虚影`/`碎星虛影` @ `[20,445,265,95]` | DoNothing | `周本_读进度_未满` |
| S2 | 卡片不在应有位置 = **满 600/600**（卡片被挤到最右） | 同上未命中 → 落到 `周本_碎星虚影_分派`（DirectHit，必定命中） | DoNothing | `周本_左滑找碎星虚影` |

> `周本_碎星虚影_分派` 在两个 case 里都被覆盖成 `[周本_左滑找碎星虚影]`（改造前 case A 是 `[周本_领完即结束]`）。
> **窄 ROI 是刻意保留的**：放宽会把滑动后找到的满卡片也判成「未满」。

## 二、S1 之后：点卡片 → 领奖 → 三态判定

流程：`周本_读进度_未满[C]` → `周本_点击碎星虚影_领奖`（点卡片 OCR 框，post_delay 3000）
→ `周本_奖励领取页_点外边缘`（**盲点** `[1120,360]`，post_delay 1200，pre_wait_freezes 800）→ `周本_领奖后_判定`

| # | 情形 | 判据 | 下一跳 | 结果 |
|---|---|---|---|---|
| C1 | 点卡片直接进了 BOSS 选择页（≥100/600 时通常如此，不出领奖页） | `戈里刻虚影`/`尼克罗虚影`/`诺斯虚影` @ `[100,333,800,220]` | `活动探索_戈里刻虚影` → 挑战链 | 直接开始刷 |
| C2 | 卡片仍在应有位置（领奖页关掉后回到原状） | `碎星虚影` @ `[20,445,265,95]`，`max_hit: 2` | `活动探索_碎星虚影`（整条带点卡片）→ BOSS 选择页 | 继续刷 |
| C3 | 卡片挪走了（= 领奖完成） | 前两条都未命中 → `周本_碎星虚影_分派` | `周本_左滑找碎星虚影` | 找回卡片再决定 |

> **领奖页只在进度 0/600 时出现**（用户 2026-09-22 说明）；其余进度点卡片一般不出它。
> 所以「点外边缘」是容错写法：出现了就关掉，没出现就靠 C1/C2/C3 把状态判回来。

## 三、S2 / C3 之后：左滑找回 → 按进度分派

`周本_左滑找碎星虚影`（DirectHit Swipe `(620,490)→(120,490)`，`max_hit: 3`，post_delay 1000）
→ next 循环扫：`周本_BOSS选择页_已进入`（滑出戈里刻就顺势挑战）/ `周本_碎星虚影_滑动后已找到` / 自己 / **兜底**
（末位兜底 = `周本_找不到碎星虚影_收尾`：滑不动了就干净收尾，不报错）
→ `周本_读取报酬`（读顶部带 `[20,185,1240,100]`：`600/600|\d+/600|6007600|6001600|本周报酬`）
→ `周本_读进度_已满[C]`（agent 重算目标 = 计算次数 + 追加次数）
→ `周本_按进度分派`（OCR **满进度** `600/600|6007600|6001600`，`timeout: 1500`）

| # | 情形 | 判据 | 下一跳 | 结果 |
|---|---|---|---|---|
| D1-A | 满进度 + case A（领完即结束（若未满则继续刷取直到领完）） | OCR 命中满（覆盖 next） | `周本_领完即结束` → `通用-返回主页` | **一场不打，收工** |
| D1-B | 满进度 + case B（领完依然进行挑战） | OCR 命中满（默认 next） | `活动探索_碎星虚影` → 挑战链 | 打「自选次数」场 |
| D2 | 未满（OCR 未命中，最多等 1.5s） | `on_error` | `周本_进度未满_继续刷` → `活动探索_碎星虚影` | 刷到补满（+ case B 的自选次数） |

## 五、选项矩阵（三处选择如何叠加）

### 5.1 「领奖后」`周本_领奖后处理`（本次改造重点）

| case | 覆盖内容 | 追加次数 | 满进度（600/600）时 | 未满时 |
|---|---|---|---|---|
| **领取完奖励就结束（若未满则继续刷取直到领完）**（默认） | `周本_碎星虚影_分派`→左滑；`活动探索_第五关`/`虚影阿瑞斯`→跳过 `活动探索_已存在`；`周本_按进度分派`→`周本_领完即结束` | **0** | **收工**：领完即结束 → 返回主页 | 刷到**补满 600**为止 |
| **领取完奖励依然进行挑战** | `周本_碎星虚影_分派`→左滑；`活动探索_第五关`/`虚影阿瑞斯`→跳过 `活动探索_已存在` | **自选次数 1–10**（`周本_挑战次数`） | 照打自选次数 | 补满 + 自选次数 |

### 5.2 「周本关卡选择」

| case | 每关微晶（决定计算次数） | `活动探索_戈里刻虚影` | `活动探索_战斗结束3` | `周本_次数分派` |
|---|---|---|---|---|
| 第一关45微晶 | 45 | `[虚影阿瑞斯, 上滑, 自己]` | `[获得物品, 周本_挑战完成_阿瑞斯, 自己]` | `[次数已达, 活动探索_虚影阿瑞斯]` |
| 第五关120微晶 | 120 | `[第五关, [JumpBack]下滑, 自己]` | `[[JumpBack]获得物品, 周本_挑战完成_宙斯, 自己]` | 用默认 `[次数已达, 活动探索_第五关]` |

### 5.3 次数目标（agent `weekly_run_counter`）

```
target = ceil((总量 - 当前进度) / 每关微晶) + 追加次数
        └ 满进度时 0 ─┘              └ case A = 0；case B = 自选次数 ┘
```

- 进度来源：活动探索页顶部「本周报酬微晶 x/600」（`周本_读取报酬` 的 OCR 结果，agent 用
  `context.run_recognition` 复用同一节点）。总量从页面读（兜底 600）。
- 每关微晶：从「周本关卡选择」当前 case 名解析（`第五关120微晶` → 120）。
- 读数时机：`周本_读进度_未满`（应有位置、必为未满）与 `周本_读进度_已满`（左滑找回后）。
- **读不到就什么都不改**：保持 init 兜底（case A=1，case B=自选次数），异常全部自吞，不会拖死任务。

## 六、异常与容错分支

| 情形 | 现在会怎样 | 出处 |
|---|---|---|
| 顶部报酬带 OCR 读不到 | `周本_读取报酬` 的 `on_error` → `周本_读不到报酬也去点碎星虚影` → 直接点卡片挑战（不判满/未满） | 节点 `on_error` |
| agent 读进度失败或抛异常 | 只写一条 warning，目标保持兜底值，流程照常往下 | `_read_progress` 内层 try/except |
| 领奖页没出现（非 0/600） | 「点外边缘」是盲点，可能落在普通页面上；随后靠 C1/C2/C3 三态自愈 | 用户说明 + 判定节点 |
| 满进度却仍进了挑战循环 | `target=0` 也算「已达」→ 打完一场即返回主页 | `WeeklyRunReached` |
| 战斗中弹「本周可领取的上限已满」 | `[JumpBack]活动探索_奖励上限确认` 点 `[788,435]` 关掉后继续 | 既有节点 |
| **左滑 3 次仍找不到卡片** | 兜底生效：`周本_左滑找碎星虚影` 的 `max_hit` 用尽（该条目在 next 扫描里被**跳过**）→ 末位 `周本_找不到碎星虚影_收尾`（DirectHit）→ `周本_领完即结束` → `通用-返回主页`，**干净收尾**，不再 `NextList.Failed` | 2026-09-22 补；与主线芯片仓满同类问题的治法 |
