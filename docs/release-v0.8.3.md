# v0.8.3

## 更新

- 扫荡单批上限调整为 30，适配进入页面时默认选择当前可扫荡最大次数。
- 每日探索、主线和活动按实际选中值校准，超出上限分批继续；修正活动自定剩余次数重置问题。
- 修正扫荡设置页标题被误识别为“扫荡成功”而提前结束任务的问题。
- 角斗场支持非战斗页面接续，恢复已有角色池和路线，不再在每次任务启动时清空进度。
- 角斗场多格角色优先摆放；首次清空交给 Pipeline，补拖不重复清空。
- 角斗场按视图选中背景区分平面、立体，避免已经平面时再次点击切成立体。
- 芯片仓库采用动态行中心定位，减轻滑动累计误差；完成 R5 检测后遇到 R4 结束并返回主页。
- 修正部分锁定状态识别偏差，补充相关离线测试。

## 配套与边界

- 配套 UI：MCCAvalonia v0.1.3；识别框架：MaaFramework v5.12.3。
- 未包含“单个任务失败后继续后续任务”功能。
- 角斗场接续依赖本地状态，不包含战斗进行中的画面接续。
- 最新角斗场视图与多格修正、30 次扫荡已完成离线回归，尚未完整实机验证。
- 本次产物先保留为 Release 草稿，供验证后公开。
