# 角斗场多格角色编队修复

对应 Issue #12：多格角色在旧队伍或先摆好的单格角色占位时，可能无法完成替换。

## 调整

- Pipeline 执行原有的一次清空后，按底部两种视图的选中背景判断状态。
  已是平面不点击；只有立体时点击切换，并再次确认平面后编队。Agent 不重复清空。
- 编队执行入口识别“清空队伍”按钮，不再依赖立体视图中位置会变化的“此面向敌”。
- 按角色占格数量降序安排拖拽，同占格数量保留原阵容优先顺序。
- 每次仍重新读取右侧列表坐标；当前不可见的角色不会盲拖。
- 补拖仅处理结束复核时仍留在右侧的角色，不再次清空队伍。
- 保留原有重试上限、结束统一复核和停止任务检查。
- 纯单格阵容不额外增加清空操作。

流程仍使用现有 MPE/Pipeline 编队执行节点，未增加新的页面节点或盲目重试分支。

## 验证

`tools/test_jdc_multicell.py` 验证占格排序、排序稳定性、纯单格优先级，以及三双格加两单格合法布局。
`tools/test_jdc_team_verification.py` 验证结束复核、清空只在重试循环外执行一次和停止检查。

离线测试不能替代游戏实机验证，尚需遇到多双格阵容时确认实际拖拽结果。
