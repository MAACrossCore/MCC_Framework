# 页面导航体系

页面导航以录制 `20260831-230756-75001e / 界面逻辑录制` 为第一版依据。
完整机器可读图谱位于 `assets/navigation/page_graph.json`，MPE 可执行节点位于
`assets/resource/pipeline/base/界面导航.json`。

## 规则

1. 页面识别优先使用标题、页签、固定按钮文字等稳定 UI，不把角色外观作为唯一特征。
2. 先判断是否已经到达目标页；相邻或隔一层页面时直接接续。
3. 当前页距目标超过两层时，优先点击主界面键，再从主界面走最短已知路径。
4. 点击后必须识别到目标页才算跳转完成；加载未结束时等待并允许重试一次。
5. 流程和页面切换写在 Pipeline，Agent 只提供 OCR、计算和单次原子能力。
6. 新增页面时，同时补充图谱页面、路径边、Pipeline 识别节点和 MPE 坐标。

## 主干页面链

```text
主界面
├─基地总览─基地建筑列表
│          ├─驻员状况
│          └─自己的订单库↔好友订单库
├─任务（日常↔周常、主线↔支线）
├─编队编辑─队伍列表/队员选择
├─队员列表
├─构建
├─补给站─礼包/万物贸易所/限时贸易所
├─勘探指南─每日任务/每周任务/本期任务
└─出击-二级菜单
   ├─模拟军演─镜像竞技─竞技场对手页面
   ├─每日探索─资源采集/芯片嵌合/跃升行动
   └─活动探索─碎星虚影─周本选择页
```

## 可复用入口

任务可以在 `next` 中调用以下节点：

- `导航到_主界面`
- `导航到_基地总览`
- `导航到_自己的订单库`
- `导航到_出击二级菜单`
- `导航到_竞技场对手页面`
- `导航到_每日探索分类页`
- `导航到_资源采集`
- `导航到_活动探索选择页`
- `导航到_周本选择页`

入口均先检查当前页面，因此从目标页或附近页面启动时不会先退回主界面。

## 数据说明

`page_graph.json` 使用 `1280×720` Maa 坐标。每个页面包含：

- 稳定识别文字 `features`
- 对应 Pipeline 识别节点 `pipeline_recognizer`
- 已有任务归属 `task_refs`
- 原始录制截图序号 `sample_steps`

每条边包含来源、目标、动作、坐标和验证状态。`status=observed` 表示录制中实际出现；
后续若新增推断路径，应使用 `status=inferred`，实机确认后再改为 `observed`。
