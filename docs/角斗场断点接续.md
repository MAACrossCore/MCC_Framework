# 角斗场断点接续

任务入口先加载现有 `agent/jdc_state.json`，不再无条件重置角色池和路线。
仅进入新一轮的“入场确认”时，以及本轮领奖完成后，使用原有重置能力。

Pipeline 根据当前页面分派：

- 选角页：继续选角，沿用已获得角色。
- 编队页：清空一次、切平面，再按已恢复角色池完成编队。
- 回合选择页：若保存状态确认已编队，直接推进关卡；否则进入编队。
- 战斗胜利、战斗失败、全部领取页：进入对应原有后续节点。
- 随机模式和角斗场入口页：进入原有入场流程。
- 不属于可识别页面：使用原有主页导航进入。

Agent 新增的能力仅为加载状态、判断已保存编队是否完成。
页面识别、接续顺序和跳转都在 `assets/resource/pipeline/base/角斗场.json` 中，附带 MPE 节点位置。

边界：依赖本地保存进度，没有承诺从丢失的存档中恢复不可见角色；
不新增战斗中途的战斗画面识别，当前分派覆盖角斗场非战斗页面和战斗结算。
离线测试覆盖恢复不重置、损坏文件不删除、停止检查和页面连线，实机仍需验证。
