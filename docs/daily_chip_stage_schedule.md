# 每日探索芯片本开放表

MFA 在每次生成“每日探索 -> 关卡选择”设置面板时读取电脑本地日期，
只在下拉框中显示当天实际开放的芯片本。关闭并重新打开任务设置即可按
新的电脑日期刷新；周六和周日显示全部八个芯片本。

| 芯片本 | 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 鼓军嵌合 | ✓ | ✓ |  | ✓ | ✓ | ✓ | ✓ |
| 光杵嵌合 | ✓ | ✓ | ✓ |  | ✓ | ✓ | ✓ |
| 注刈嵌合 | ✓ | ✓ | ✓ | ✓ |  | ✓ | ✓ |
| 链接嵌合 | ✓ |  |  |  |  | ✓ | ✓ |
| 体魄嵌合 |  | ✓ |  |  |  | ✓ | ✓ |
| 侵蚀嵌合 |  |  | ✓ |  |  | ✓ | ✓ |
| 迅刃嵌合 |  |  |  | ✓ |  | ✓ | ✓ |
| 矛盾嵌合 |  |  |  |  | ✓ | ✓ | ✓ |

可复现 UI 补丁位于
`ui_custom/MFAAvalonia/laa-daily-chip-stage-schedule.patch`。日期映射集中在
`TaskOptionGenerator.DailyChipStageSchedule`，后续调整开放日时只需修改该表。
